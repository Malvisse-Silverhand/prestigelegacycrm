# Bahasa Malaysia review sheet: Medical

Compliance-sensitive Bahasa Malaysia strings for the Medical card module, with the English source. Layout follows [BM-REVIEW.md](BM-REVIEW.md) section B. **Nothing here is approved.** Status for every row is `Not reviewed`. Keys are in `lib/storyboard/i18n/dict/medical.{en,bm}.ts` unless a file is named.

Note for the reviewer: the guarantee letter (GL) is written "surat pengesahan (GL)" in BM on purpose, so no "jamin/jaminan" wording appears anywhere in the module. Please confirm this is the term the operator uses.
