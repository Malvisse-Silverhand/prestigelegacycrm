How a client portal link lives and dies
One link per certificate, issued from My Sales › Servicing. It carries no password — the token is the credential — so everything below is about keeping the blast radius small.
1
Certificate goes inforce
Agent records the certificate in Submit Case. The lead moves to Servicing and the closing date follows the commencement date.
GATE: status = inforce
2
Agent issues the link
From the client’s panel in Servicing. A random token is minted, stored against the certificate, and sent over WhatsApp.
/c/9f3c2ab74e1d
3
Client opens it
No sign-in, no app, no account. Read-only. Every open bumps a counter the agent can see, so they know it landed.
VIEW ONLY · NOINDEX
4
It closes
Revoked by hand, or closed by itself the moment the certificate stops being inforce. Same dead-end page either way.
404, NEVER 403
